# Конфигуратор соединительного узла

Статус: актуальная модель после issue #33. Силовой расчёт подробно описан в [`CONNECTIONS.md`](CONNECTIONS.md), новые проверки и 3D-геометрия — в [`JOINT_STRENGTH_AND_VISUALIZATION.md`](JOINT_STRENGTH_AND_VISUALIZATION.md).

## 1. Физическая сборка

Один межмодульный стык состоит из:

```text
верхний модуль
2 ребра ножки -> обычная проходная гайка My
                         |
                         | болт Mx проходит свободно
                         v
нижний модуль
4 ребра -> длинная соединительная гайка Mx
                         ^
                         | болт Mx ввинчивается сюда
```

Болт работает резьбой только в длинной гайке. Проходная гайка имеет больший номинальный диаметр и используется как сварная деталь ножки и отверстие для болта.

## 2. Что пользователь выбирает, а что вычисляется

В `auto` пользователь задаёт конструкцию/нагрузки и проектные параметры затяжки/запаса, а конфигуратор сам выбирает:

```text
диаметр и класс болта
проходную гайку
длинную гайку
длину болта
длину зацепления
reff
сварочный материал
катет и число участков шва
```

В ручном режиме пользователь фиксирует уже купленные болт, класс, проходную гайку, длину болта, зацепление, сварочный материал и геометрию шва. Длинная гайка и `reff` остаются производными от болта.

Проектные параметры issue #33 задаются явно и работают в обоих режимах:

```text
момент затяжки T
nut factor K
разброс преднатяга Gamma
минимум Anut/Arib >= 2
минимум Aeff,weld/Arib = 2…3, default 2.5
```

## 3. Свободный проход болта

Для проходной гайки используется базовый внутренний диаметр метрической резьбы:

```text
D1 = D - 1.082532·P
```

Предварительное условие:

```text
D1 - dbolt >= 0.5 мм
```

Это геометрический фильтр. Фактический проход должен быть подтверждён реальной деталью, так как профиль зависит от допуска, покрытия и производителя.

Для M24 минимальной проходной гайкой текущего каталога остаётся M30.

## 4. Длинная гайка, зацепление и длина болта

Длинная соединительная гайка всегда имеет резьбу болта. Расчётная длина каталога:

```text
Lcoupling = 3d
```

Эффективный радиус передачи момента:

```text
reff = s/2
```

Зацепление по умолчанию:

```text
Lengagement = 2d
nturns = Lengagement/P
```

Минимальная длина болта:

```text
Lrequired = hclearance + Lengagement + 2 мм
```

После чего выбирается ближайшая большая стандартная длина. Для M24/M30 получается:

```text
длинная M24×72
зацепление 48 мм = 16 витков
Lrequired = 75.6 мм
болт M24×80
```

`2d` остаётся правилом компоновки, а не доказанной проверкой срыва резьбы.

## 5. Нетто-сечение обеих гаек

Issue #33 добавляет обязательный геометрический фильтр:

```text
Ahex = sqrt(3)/2·s²
Ahole = pi·D1²/4
Anut,net = Ahex - Ahole
Arib = pi·dbar²/4
Anut,net / Arib >= ksection
ksection >= 2
```

Проверяются отдельно длинная и проходная гайка. Кандидат не проходит автоподбор, если хотя бы одна из них имеет недостаточное нетто-сечение, даже если сам болт проходит по `Rbs/Rbt`.

Этот критерий — дополнительный запас проекта, а не замена проверки внутренней/наружной резьбы, bearing или prying.

## 6. Момент затяжки

Преднатяг оценивается через:

```text
T = K·F0·d
F0,nom = T/(K·d)
F0,max = (1+Gamma)·F0,nom
F0,min = (1-Gamma)·F0,nom
```

По умолчанию:

```text
T = 200 Н·м
K = 0.20
Gamma = 0.25
```

Для прочностной проверки берётся верхняя граница:

```text
Nt,strength = F0,max + Nt,external
```

Поэтому больший момент затяжки уменьшает оставшийся растягивающий резерв. Это намеренно консервативно: пока жёсткости болта и зажатого пакета не заданы, внешняя разделяющая сила целиком добавляется к преднатягу, а перенос среза трением не кредитуется.

## 7. Срез от наклонной ножки

Каждый кандидат использует реальные FEM-resultants одного load case. Сила верхней двухреберной ножки раскладывается относительно вертикальной оси болта:

```text
Faxis = F·eb
Fperp = F - eb(F·eb)
Nt,direct = max(0,-Faxis)
Ns,direct = |Fperp|
```

Момент добавляет:

```text
Nt,external = Nt,direct + |Mb|/reff
Ns = Ns,direct + |T|/reff
```

Таким образом поперечная составляющая наклонной силы явно попадает в срез болта и видна пользователю.

## 8. Силовая проверка болта

Для каждого кандидата:

```text
Nbs = Rbs·Ab·ns·γc
Nbt = Rbt·Abn·γc
Ubolt = sqrt((Ns/Nbs)² + (Nt,strength/Nbt)²)
PASS: Ubolt <= 1
```

Также выводятся `F0,max`, `Upreload`, внешнее растяжение, прямой срез от наклонной силы и остаток растягивающего резерва.

Автоподбор начинает с класса 8.8 и минимального стандартного диаметра. Если ряд 8.8 не проходит всю совокупность критериев, проверяются 10.9/12.9; классы 5.6/5.8 остаются в ручном режиме и справочнике.

## 9. Сварка

Для каждого конца ребра силовая проверка использует совпадающие `N/V/T/M`. В issue #33 поверх неё добавлен запас эффективной площади:

```text
teff = beta_f·kf
Aeff = teff·lweff
Aeff >= kweld·Arib
2 <= kweld <= 3
kweld,default = 2.5
```

Итоговая длина — максимум силовых требований, конструктивного минимума и площади `kweld·Arib`.

Коэффициент `2…3×` — дополнительное требование этого проекта. Нормативная идея, используемая в проверке, — effective weld area = effective throat × effective length; приложение не приписывает AISC/СП требование именно `2.5×`.

## 10. Фиксация выбранного узла в предельных расчётах

Последовательность остаётся принципиально жёсткой:

```text
эксплуатационная FEM-огибающая
        ↓
auto/manual физический узел
        ↓
узел фиксируется
        ↓
боковая несущая способность
статическая масса на вершине
поиск максимальной высоты
```

Во время поиска предела болт/гайки не могут автоматически увеличиваться. Проверяется именно выбранная физическая сборка, включая её момент затяжки и area-reserve критерии.

## 11. 3D-визуализация

Визуализация теперь строится из геометрии правильного октаэдра, а не из условных радиальных линий:

- длинная гайка — 4 фактических направления рёбер;
- проходная гайка — 2 направления ножек верхнего модуля;
- диагональные ножки имеют угол `35.264°` к оси болта;
- выбирается ближайшая боковая грань гайки для каждого ребра;
- показываются точки контакта и зоны сварки;
- гайки и болт имеют заполненные грани с процедурной металлической текстурой;
- резьба не визуализируется.

Схема предназначена для визуального аудита компоновки, а не для замены CAD.

## 12. Что ещё не доказано

Текущий конфигуратор не закрывает:

- срыв резьбы по фактическому материалу и длине зацепления;
- реальные поля допуска/покрытие/смазку;
- bearing, локальный изгиб грани, prying;
- распределение внешнего растяжения по жёсткости болта и пакета;
- friction-grip перенос поперечной нагрузки;
- точную геометрию сварных валиков, дефекты, остаточные напряжения;
- усталость и самоотвинчивание;
- податливость узла в глобальной FEM.

## 13. Автоматическая проверка

CI проверяет конфигуратор двумя слоями:

```text
Joint configurator
Joint strength and visualization
```

В частности регрессии подтверждают M24→M30/M24×72/M24×80, старый эталонный подбор при `T=0`, влияние момента затяжки, минимум 2× по нетто-сечению гаек, 2–3× по эффективной площади шва, срез от наклонной силы и точные направления 4+2 рёбер в 3D-модели.
