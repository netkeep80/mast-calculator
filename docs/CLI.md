# Mast Calculator CLI

`mast-calc` is a Node adapter over the same compiler-emitted application/design/reporting packages used by the Web application. It contains no independent engineering formulas or FEM implementation.

## Runtime

Use Node.js 24.x.

The repository helper builds the canonical TypeScript core before launching the CLI:

```bash
npm run cli -- validate project.json
npm run cli -- calculate project.json
```

For repeated commands, build once and invoke the adapter directly:

```bash
npm run build:core
node apps/cli/mast-calc.mjs calculate project.json
```

The CLI intentionally imports `.build/packages`; it therefore exercises the same compiler-emitted runtime artifact that CI and headless consumers use.

## Commands

```bash
mast-calc validate project.json
mast-calc calculate project.json
mast-calc optimize project.json
mast-calc design project.json -o mast.design.json
mast-calc export-obj project.json -o mast.obj
mast-calc export-eskd project.json -o mast-eskd.html
mast-calc export-report project.json -o calculation.html
mast-calc export-procurement project.json -o procurement.html
```

`calculate` automatically uses the optional `guys` section from `mast-calculator/project/v1`; there is no separate incompatible guy-wire input format.

The export commands only write bytes/text to the filesystem. OBJ, ESKD, calculation report, procurement estimate and design-package contents are generated by the existing pure packages.

## Options

- `--json` — emit a versioned machine-readable result for `validate`, `calculate` or `optimize`.
- `--quiet` — suppress human success messages and interactive progress.
- `-o, --output <file>` — write the produced output/artifact to a file. Export commands require it.
- `--timeout <ms>` — terminate the isolated calculation Worker after the deadline.
- `-h, --help` — print command help.

Paths are passed as normal Node filesystem paths; filenames with spaces are covered by the same CLI oracle tests on Ubuntu, macOS and Windows.

## Machine output

Calculation and optimization machine output uses:

```text
mast-calculator/result-summary/v1
```

It is deliberately a compact external contract rather than a serialization of the internal `CalculationResult`. It carries stable engineering summary values, the source project schema/input, optional optimization/guy summary and provenance such as tool/core version and available GitHub build metadata.

Example:

```bash
node apps/cli/mast-calc.mjs calculate project.json --json > result.json
```

Machine data is written only to stdout. Errors are written to stderr. Interactive progress is disabled for `--json`, so progress text cannot corrupt redirected JSON.

When `-o` and `--json` are combined for an artifact command, stdout contains a small JSON write receipt with the resolved output path, media type and byte count; the artifact itself is written to the requested file.

## Human output and progress

Without `--json`, calculation commands return a compact human summary. When stderr is attached to a TTY, progress reported by the application use-case is relayed through the Node Worker and rendered on stderr with the current phase/percentage.

The Worker boundary is intentional: the engineering calculation is CPU-bound and synchronous, so the parent process can still respond to `Ctrl+C` or a watchdog timeout by terminating the isolated Worker. Direct application consumers also have the portable cancellation contract introduced by the application layer.

## Exit codes

The CLI uses stable process exit categories:

| Code | Category | Meaning |
| ---: | --- | --- |
| 0 | success | Command completed successfully |
| 2 | input/schema | Malformed JSON, unsupported schema shape, invalid project semantics or CLI argument error |
| 3 | unsupported configuration | Known command/configuration cannot be executed by the current application |
| 4 | numerical/convergence | Numerical solver or convergence failure |
| 5 | I/O | Project read or output filesystem failure |
| 6 | cancelled | `Ctrl+C`, termination signal or `--timeout` watchdog |
| 7 | internal | Unclassified/internal invariant failure |

A structurally valid calculation that returns `passes: false` is **not** a process failure for `calculate`; the result contract reports the failed engineering criteria. This avoids conflating a valid engineering answer with a broken CLI execution.

## Reproducibility

The same `mast-calculator/project/v1` package and software version must produce numerically equivalent summaries through direct application calls and the CLI. CI runs exact summary oracles and the CLI adapter on:

```text
ubuntu-latest
macos-latest
windows-latest
```

The project package, design package, result summary and internal calculation snapshot have different responsibilities; see `docs/PROJECT_PACKAGE.md` for the artifact taxonomy and versioning policy.
