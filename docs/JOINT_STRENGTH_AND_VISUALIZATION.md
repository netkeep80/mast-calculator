# Усиленный расчёт и 3D-визуализация соединительного узла

Статус: проектный контракт issue #33.

## 1. Что именно проверяется

Соединительный узел состоит из вертикального болта, длинной соединительной гайки нижнего модуля с четырьмя приваренными рёбрами и проходной гайки ножки верхнего модуля с двумя приваренными рёбрами.

В issue #33 к существующим проверкам добавляются четыре независимых слоя:

1. геометрический запас нетто-сечения обеих гаек;
2. минимальная эффективная площадь углового шва относительно сечения ребра;
3. преднатяг болта от фактического момента затяжки;
4. явное разложение наклонного воздействия верхних рёбер на осевую и поперечную к болту составляющие.

Эти проверки не заменяют уже существующие `Rbs/Rbt`, `Ab/Abn`, силовой расчёт углового шва, local/global buckling и FEM.

## 2. Нетто-сечение гайки

Для шестигранной гайки с размером под ключ `s` площадь поперечного сечения наружного шестигранника:

```text
Ahex = sqrt(3)/2 * s^2
```

Из неё вычитается отверстие по базовому внутреннему диаметру резьбы `D1`:

```text
Ahole = pi*D1^2/4
Anut = Ahex - Ahole
```

Площадь одного ребра:

```text
Arib = pi*dbar^2/4
```

Дополнительный проектный критерий issue #33:

```text
Anut / Arib >= 2.0
```

Он является геометрическим запасом материала гайки и не выдаётся за нормативную проверку резьбы, смятия, локального изгиба грани или prying.

## 3. Эффективная площадь углового шва

Для равнополочного углового шва эффективное горло принимается в существующей модели как:

```text
teff = beta_f * kf
Aweld = teff * leff
```

Такой способ определения эффективной площади соответствует общему принципу расчёта угловых швов: эффективная площадь равна эффективной длине, умноженной на эффективную толщину горла. Для равных катетов теоретическое горло близко к `0.707*k`.

Issue #33 дополнительно требует производственный запас площади в диапазоне 2–3 площадей ребра. В проекте он задаётся коэффициентом `kweld,area`, по умолчанию `2.5`:

```text
Aweld >= kweld,area * Arib
2.0 <= kweld,area <= 3.0
```

Это дополнительный консервативный критерий проекта, а не утверждение, что СП 16 или AISC требуют именно коэффициент 2.5. Требуемая длина шва берётся как максимум силового расчёта, нормативного минимума и этого дополнительного критерия площади.

## 4. Момент затяжки и преднатяг

Для torque-controlled tightening используется инженерное соотношение:

```text
T = K * F0 * d
F0,nom = T / (K*d)
```

где `K` — nut factor, включающий трение в резьбе и под опорной поверхностью.

Из-за разброса torque-to-preload учитывается относительная вариация `Gamma`:

```text
F0,max = (1 + Gamma) * F0,nom
F0,min = max(0, 1 - Gamma) * F0,nom
```

Для консервативной проверки растяжения болта используется максимальный преднатяг:

```text
Nt,strength = F0,max + Nt,external
```

и именно `Nt,strength` входит в совместную проверку растяжения и среза. Поэтому увеличение момента затяжки уменьшает остающийся растягивающий резерв.

Это упрощённая верхне-консервативная модель: пока не известны жёсткости болта и зажатых деталей, внешняя разделяющая сила целиком добавляется к преднатягу. Friction-grip разгрузка поперечного среза не кредитуется.

Публичный ориентир для формулы `T=KFd` и разброса преднатяга: NASA-STD-5020A, Appendix A, а также NASA Fastener Design Manual. Для реальной сборки `K` должен быть подтверждён состоянием резьбы, покрытием и смазкой.

## 5. Срез от наклонных рёбер

Ось болта `e` вертикальна. Результирующая сила верхней двухреберной ножки `F` раскладывается:

```text
Faxis = F dot e
Fperp = F - e*(F dot e)
```

Отсюда:

```text
Nt,direct = max(0, -Faxis)
Ns,direct = |Fperp|
```

Момент вокруг оси болта добавляет эквивалентный срез `|T|/reff`, а поперечный изгибающий момент — эквивалентное растяжение `|Mb|/reff`.

```text
Nt = Nt,direct + |Mb|/reff
Ns = Ns,direct + |T|/reff
```

Таким образом поперечная составляющая силы наклонных рёбер уже не может потеряться в осевом представлении узла и отдельно выводится пользователю.

## 6. Геометрия 3D-схемы

Визуализация должна показывать не условные радиальные отрезки, а направления рёбер правильного октаэдра вокруг одного межмодульного узла.

Для ребра длиной `a` и высоты модуля `h=a*sqrt(2/3)` диагональная ножка имеет угол к вертикальной оси:

```text
theta = acos(h/a) = acos(sqrt(2/3)) ~= 35.264 deg
```

У длинной гайки показываются четыре ребра нижнего модуля:

- два горизонтальных ребра верхнего треугольника;
- две диагональные ножки вниз.

У проходной гайки показываются две диагональные ножки верхнего модуля вверх.

Для каждого ребра выбирается ближайшая боковая грань шестигранника, показывается точка контакта, угол оси ребра к плоскости грани и две условные зоны углового шва по сторонам контакта.

Гайки рисуются заполненными гранями с процедурной «металлической» штриховой текстурой. Это наглядная инженерная схема, а не CAD-модель резьбы или фактической формы сварного валика.

## 7. Граница доказанности

Новые проверки существенно усиливают внутреннюю модель, но всё ещё не моделируют:

- срыв внутренней/наружной резьбы по фактическому материалу гайки;
- смятие и локальный изгиб граней гайки;
- контакт и prying;
- реальную податливость болт/гайка/сварка в глобальной `K`;
- friction-grip перенос поперечной нагрузки;
- остаточные сварочные напряжения и дефекты;
- усталость и самоотвинчивание.

Поэтому итог остаётся расчётным прототипом и требует натурной проверки узла перед применением как ответственной конструкции.
