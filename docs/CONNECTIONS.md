# Межмодульный болт, гайки и сварные концы рёбер

Статус: расчётная модель connection-layer после issue #33. Практическая конфигурация описана в [`JOINT_CONFIGURATOR.md`](JOINT_CONFIGURATOR.md), а новые критерии и 3D-геометрия — в [`JOINT_STRENGTH_AND_VISUALIZATION.md`](JOINT_STRENGTH_AND_VISUALIZATION.md).

## 1. Граница модели

Глобальная пространственная рамная FEM по-прежнему считает общие узлы идеально жёсткими. После FEM connection-layer проверяет физические метизы, геометрический запас гаек и сварные концы. Податливость соединения пока не возвращается в глобальную матрицу `K`.

Для каждого load case используются совпадающие `N/V/T/M`; независимые максимумы разных направлений ветра не смешиваются.

## 2. Физическая сборка

На каждом внутреннем FEM-узле сходятся шесть рёбер:

```text
нижний модуль: 4 ребра -> длинная соединительная гайка Mx
верхний модуль: 2 ребра -> проходная гайка My, y > x
                         | болт Mx проходит свободно
                         v
                    длинная Mx
```

Болт не работает резьбой в проходной гайке. Он проходит через неё и ввинчивается в длинную гайку. При `N>1` внутренних стыков `3·(N−1)`.

## 3. Сила наклонной ножки и срез болта

Из FEM суммируются концевые усилия двух рёбер верхней ножки одного load case:

```text
Fjoint = F1 + F2
Mjoint = M1 + M2
```

Для вертикальной оси болта `eb=[0,0,1]`:

```text
Faxis = Fjoint·eb
Fperp = Fjoint - eb·Faxis
Nt,direct = max(0,-Faxis)
Ns,direct = |Fperp|
```

То есть наклонная сила не сводится к одной осевой компоненте: поперечная часть явно становится прямым срезом болта и сохраняется в `shearFromInclinedForceN`.

Момент раскладывается аналогично:

```text
T  = |Mjoint·eb|
Mb = |Mjoint - eb(Mjoint·eb)|
reff = s/2
Nt,external = Nt,direct + Mb/reff
Ns = Ns,direct + T/reff
```

Сжатие контакта не превращается в фиктивное растяжение болта и не используется как кредит против `Mb/reff`, поскольку точное распределение контактных давлений и prying пока не моделируются.

## 4. Геометрия и нетто-сечение двух гаек

До силовой проверки выполняются геометрические условия:

```text
D1(clearance nut) - dbolt >= 0.5 мм
Lengagement помещается в длинную гайку
Lbolt >= hclearance + Lengagement + монтажный запас
```

Дополнительно issue #33 вводит независимый запас нетто-сечения обеих гаек:

```text
Ahex = sqrt(3)/2*s²
Ahole = pi*D1²/4
Anut,net = Ahex - Ahole
Arib = pi*dbar²/4
Anut,net / Arib >= 2.0
```

Проверяются и длинная, и проходная гайка. `FAIL` этого критерия делает физический узел непригодным даже при достаточной прочности самого болта. Это дополнительный геометрический критерий проекта, а не замена расчёта срыва резьбы, смятия или локального изгиба грани.

Для M24 практическая компоновка по-прежнему даёт минимальную проходную M30, длинную M24×72 и болт длиной 80 мм при зацеплении `2d`.

## 5. Преднатяг от момента затяжки

Для torque-controlled tightening используется инженерная связь:

```text
T = K·F0·d
F0,nom = T/(K·d)
```

Из-за разброса трения задаётся `Gamma`:

```text
F0,max = (1+Gamma)·F0,nom
F0,min = (1-Gamma)·F0,nom
```

Проектные значения по умолчанию:

```text
T = 200 Н·м
K = 0.20
Gamma = 0.25
```

Они являются явными пользовательскими/проектными параметрами и должны уточняться для фактической резьбы, покрытия и смазки.

Для проверки прочности консервативно используется максимальный преднатяг:

```text
Nt,strength = F0,max + Nt,external
```

Пока жёсткость болта и пакета деталей не определена, внешняя разделяющая сила целиком добавляется к преднатягу. Friction-grip разгрузка поперечного среза не учитывается. Поэтому увеличение момента затяжки действительно расходует растягивающий резерв болта.

Публичная справочная основа torque-preload relation: NASA-STD-5020A Appendix A / NASA Fastener Design Manual; ссылка и принятые значения выводятся в справочнике приложения.

## 6. Силовая проверка болта

Для диаметра и класса используются `Rbs/Rbt`, `Ab/Abn` из каталога проекта:

```text
Nbs = Rbs·Ab·ns·γc
Nbt = Rbt·Abn·γc
```

Совместное действие:

```text
Us = Ns/Nbs
Ut = Nt,strength/Nbt
Ubolt = sqrt(Us² + Ut²)
PASS: Ubolt <= 1
```

Также отдельно публикуются:

- `Upreload = F0,max/Nbt`;
- внешнее растяжение до затяжки;
- остаток расчётного растягивающего резерва;
- прямой срез от наклонной силы;
- полный срез после добавления `T/reff`.

Характеристическая разрывная сила `Nu=Rbun·Abn` остаётся справочной и не называется допустимой эксплуатационной нагрузкой.

## 7. Автоподбор и фиксация детали

Для каждого кандидата автоконфигуратор теперь одновременно проверяет:

```text
компоновку болт/две гайки
Anut,net >= ksection*Arib
преднатяг от T,K,Gamma
совместное растяжение+срез болта
```

`reff` пересчитывается по собственной длинной гайке кандидата. Подбор начинается с класса 8.8 и минимального стандартного диаметра.

После выбора физическая сборка фиксируется. Боковая несущая способность, статическая масса на вершине и поиск максимальной высоты используют этот же узел; автоматическое увеличение метиза внутри пробного предельного расчёта запрещено.

## 8. Сварные концы

Каждый конец ребра использует совпадающие `N, Vy, Vz, T, My, Mz` одного load case.

Круговая surrogate-модель:

```text
Qaxial = |N| + 2|M|/rw
Qshear = |V| + |T|/rw
Qw = hypot(Qaxial,Qshear)
```

Силовые границы:

```text
lw,f = Qw/(βf·kf·Rwf·γc)
lw,z = Qw/(βz·kf·Rwz·γc)
```

Конструктивный минимум:

```text
lw,min = max(4kf, 40 мм)
```

Issue #33 дополнительно требует проектный запас эффективной площади шва:

```text
teff = βf·kf
Aeff = teff·lweff
Aeff >= kweld·Arib
2 <= kweld <= 3
kweld,default = 2.5
```

Итоговая требуемая эффективная длина:

```text
lweff = max(lw,f, lw,z, lw,min, kweld·Arib/teff)
Lphysical = lweff + 10 мм·nsegments
```

Связь `effective area = effective throat × effective length` соответствует общему принципу расчёта угловых швов. Именно коэффициент `2…3×` является дополнительным консервативным критерием этого проекта, а не утверждением о требовании СП 16/AISC.

## 9. 3D-аудит узла

3D-схема строит шесть фактических направлений рёбер правильного октаэдра вокруг общего узла:

- 4 ребра у длинной гайки: два верхнего треугольника и две ножки нижнего модуля;
- 2 ножки верхнего модуля у проходной гайки;
- диагональная ножка имеет угол `acos(sqrt(2/3)) ≈ 35.264°` к оси болта;
- для каждого ребра определяется ближайшая боковая грань шестигранной гайки;
- показываются точка контакта и зона шва.

Грани гаек и болта заполнены процедурной металлической текстурой. Резьба намеренно не рисуется. Это инженерная проверочная схема, не CAD-модель фактического шва.

## 10. Что всё ещё не входит в connection-layer

После issue #33 остаются вне модели:

- срыв внутренней/наружной резьбы по фактическому материалу гайки;
- поля допуска резьбы, покрытие и реальная посадка;
- смятие, локальный изгиб грани, bearing и prying;
- точная контактная площадка и разделение внешней силы по жёсткостям болта/пакета;
- friction-grip перенос поперечной нагрузки;
- точная геометрия и дефекты сварных валиков;
- остаточные сварочные напряжения, усталость и самоотвинчивание;
- конечная вращательная/поступательная податливость узла в глобальной `K`.

Финальный узел должен быть подтверждён по реально закупленным деталям и натурным испытанием/инженерной проверкой перед ответственным применением.
