# Закупочная смета

Issue #24 добавляет в браузерное приложение закупочную ведомость для рассчитанной модульной мачты.

## Состав сметы

После расчёта основной мачты в результатах появляется карточка **«Закупочная смета»**. В документ попадают:

- арматура с фактическим диаметром каждого яруса;
- длинные соединительные гайки;
- проходные гайки;
- болты;
- стальной трос дополнительных оттяжек;
- выбранные электроды или сварочная проволока.

Печатная форма открывается отдельным HTML-документом. В ней можно ввести цену каждой позиции, получить стоимость строк и общий итог, затем вызвать `window.print()` / сохранение в PDF.

## Арматура и смешанные диаметры

Физический модуль содержит 9 рёбер. Для однородной мачты расчёт совпадает с прежней схемой:

```text
Nrib = 9 * Nmodule
Nrib,purchase = ceil(Nrib * (1 + reserve/100))
Nbar = ceil(Nrib,purchase / NpiecesPerBar)
```

После issue #22 мачта может иметь разные диаметры по ярусам. Смета не объединяет такие позиции: Ø20, Ø16 и Ø12 считаются отдельно. Закупочный запас и округление целых прутков выполняются отдельно для каждого диаметра, иначе лишние заготовки тонкой арматуры могли бы ошибочно компенсировать нехватку толстой.

В таблице указывается, для каких модулей предназначен каждый диаметр, число проектных рёбер, число доступных заготовок и масса закупленной арматуры.

Ширина пропила отдельно не моделируется. Технологический припуск, брак и запас задаются общим полем **«Запас на закупку, %»**.

## Метизы

Используется тот же физический состав унифицированного модуля, что и в расчёте сборочной массы:

```text
1 модуль = 9 рёбер + 3 длинные гайки + 3 проходные гайки + 3 болта
```

Размеры болта и обеих гаек берутся из рассчитанного соединительного узла. Для смешанного профиля это уже согласованный с issue #22 единый узел, рассчитанный по максимальному диаметру там, где это требуется моделью.

## Оттяжки после issue #23

Актуальный `main` содержит отдельную страницу `site/guys.html` с нелинейным tension-only расчётом дополнительных растяжек.

После успешного расчёта страница растяжек сохраняет для закупочной ведомости:

- тип троса;
- диаметр;
- суммарную длину каждого типа;
- массу погонного метра;
- сигнатуру мачты и нагрузки.

Основной калькулятор автоматически использует этот результат только если он совместим с текущими исходными данными: число модулей, раскрой, единый диаметр, класс арматуры, ветровое давление, оборудование и лёд должны совпадать.

Если текущая мачта имеет смешанные диаметры или сохранённый расчёт относится к другой конфигурации, автоматический импорт не выполняется. В этом случае остаются ручные поля диаметра и общей длины троса.

Если в разных ярусах выбраны разные типы троса, каждый тип попадает в смету отдельной строкой. Общий процент запаса применяется к длине каждой позиции.

Длина, сохраняемая из браузерной таблицы расчёта растяжек, имеет точность отображения 0,01 м; для закупки всё равно следует применять технологический запас.

## Сварочный материал

Для каждого модуля учитывается 18 сваренных концов рёбер. Геометрическая масса наплавленного металла:

```text
Aweld = k² / 2
mweld = rho * Aweld * Lphysical
```

Смета выводит выбранный процесс — электроды или сварочную проволоку — и увеличивает геометрическую массу на закупочный запас. Это не заменяет производственную норму расхода: огарки, разбрызгивание и технологические потери зависят от реального процесса сварки.

## Печать и стоимость

Печатный документ содержит:

- спецификацию материалов;
- количество к закупке;
- редактируемую цену за единицу;
- стоимость каждой строки;
- общий итог;
- сводку раскроя арматуры;
- источник данных по оттяжкам;
- сводку сварки;
- ограничения и допущения;
- кнопку **«Печать / сохранить PDF»**.

Backend и внешние библиотеки не требуются.

## Проверки

`tests/procurement-estimate.test.js` фиксирует:

- обычный раскрой арматуры и запас;
- разные диаметры по ярусам;
- количество метизов;
- ручной трос;
- автоматический перенос нескольких типов троса из расчёта растяжек;
- электроды / сварочную проволоку;
- состав печатного HTML;
- browser print;
- валидацию целочисленного числа частей прутка.

Команды:

```bash
npm test
npm run test:ux
npm run test:mixed-diameters
npm run test:guys
npm run check
```
