# Основные сценарии использования калькулятора

Статус: UX-контракт прототипа 1.3 для issue #27.

## Зачем нужен этот документ

После нескольких итераций в калькуляторе появились глобальный FEM, помодульный Schur-расчёт, соединения, сварка, предельные нагрузки, максимальная высота, верификация и справочные данные. Все эти возможности нужны, но пользователь не должен начинать работу с вопроса «какие из нескольких десятков полей мне сейчас заполнять?».

Интерфейс поэтому строится от **вопроса пользователя**, а не от внутренней структуры solver.

## Сценарий A. Проверить конкретную мачту

Главный вопрос:

> Выдержит ли уже задуманная мачта заданную погоду и оборудование?

Пользователь задаёт только то, что определяет реальную конструкцию и эксплуатационную нагрузку:

- количество модулей;
- закупочную длину прутка и раскрой;
- диаметр и класс арматуры;
- погодный сценарий;
- массу и парусную площадь оборудования.

Соединительный узел по умолчанию подбирается автоматически.

Главный ответ:

- проходит / не проходит;
- определяющий механизм;
- использование ребра;
- общая устойчивость;
- прогиб;
- использование соединения.

Все подробные FEM-таблицы остаются доступны ниже по раскрытию.

## Сценарий B. Подобрать конструкцию

Главный вопрос:

> Какую арматуру и какой межмодульный узел взять для заданной высоты и нагрузок?

Пользователь задаёт:

- число модулей;
- длину ребра через закупочный раскрой;
- материал;
- нагрузки/погоду.

Кнопка подбора выбирает минимальный поддерживаемый диаметр арматуры и согласованный физический узел. Результат должен показывать не только выбранный размер, но и запас по каждому критерию.

## Сценарий C. Узнать пределы конструкции

Главный вопрос:

> Что эта конструкция вообще может выдержать?

После расчёта в фокусе:

- максимальная проектная высота;
- предельная высота по сопротивлению;
- максимальная боковая сила на вершине;
- боковая сила общей потери устойчивости;
- максимальная статическая масса на вершине;
- эквивалентный объём воды;
- механизм первого предела.

Это исследовательский сценарий. Он не должен смешиваться с обычным ответом «проходит ли текущая мачта».

## Сценарий D. Проверить расчёт

Главный вопрос:

> Почему программе можно доверять и как перепроверить ответ?

В фокусе:

- краткая цепочка алгоритма от исходных данных до ответа;
- паспорт верификации;
- global FEM ↔ module Schur ↔ independent dense FEM;
- аналитические statics-oracles;
- численные residuals;
- ограничения модели;
- бумажный расчётный проект;
- справочники исходных нормативных величин.

При этом UI не должен создавать ложное впечатление внешней сертификации: независимый сторонний FEM, инженерная рецензия и натурные испытания сохраняют статус «не проверено», пока реально не выполнены.

## Общий UX-поток

```text
1. Что нужно узнать?
        ↓
2. Конструкция
        ↓
3. Условия эксплуатации
        ↓
4. Соединение
   auto по умолчанию
   manual только по раскрытию
        ↓
5. Рассчитать
        ↓
6. Короткий ответ именно на выбранный вопрос
        ↓
7. Почему получен такой ответ?
        ↓
8. Детальные таблицы / 3D / паспорт / справочники
```

## Что вычисляется автоматически и не должно выглядеть пользовательским вводом

- длина ребра `a = Lstock/n`;
- высота правильного октаэдра `h = a·sqrt(2/3)`;
- свойства выбранного класса арматуры `E`, `ν`, `Ry`, `Rm`, `ρ`;
- погодное давление для выбранного сценария;
- геометрия auto-конфигуратора соединительного узла;
- эффективный радиус соединительного узла;
- рекомендуемый сварочный материал и базовый катет в auto-режиме;
- расчётные свойства сечения `A`, `I`, `J`, `W`;
- FEM-матрицы и внутренние нагрузочные векторы.

Эти величины должны быть **видны для проверки**, но не маскироваться под обязательный ручной ввод.

## Масса физической сборки

Для прозрачности интерфейс показывает три понятных производственных показателя:

1. **масса одного ребра** — из фактической длины, диаметра и плотности арматуры;
2. **масса одного полного межмодульного узла со сваркой** — две гайки, один болт и шесть сваренных концов рёбер;
3. **масса сваренного и закреплённого модуля** — девять рёбер, три длинные гайки, три проходные гайки, три болта и 18 сваренных концов.

Масса метизов является геометрической оценкой по каталожным размерам, а не паспортной массой конкретного изделия производителя. Масса шва оценивается как объём треугольного углового шва `A≈k²/2` умноженный на принятую физическую длину и плотность стали.

Чтобы физический модуль оставался унифицированным изделием, для оценки сборочной массы каждому из 18 концов назначается **критическая требуемая физическая длина шва** из расчётной огибающей. Это консервативнее, чем индивидуально укорачивать швы на менее нагруженных рёбрах.

На текущем этапе FEM-собственный вес остаётся массой арматурных рёбер. Сборочная масса показывается отдельно и прямо помечается как производственная оценка; её автоматическое включение в global load model требует отдельного согласованного изменения физической модели, чтобы не создавать скрытую обратную связь «усилия → длина шва → масса → усилия».

## Справочники

Справочники должны показывать **ровно те значения, которыми пользуется расчёт**, из единого каталога кода.

### Арматура

Показываются:

- класс;
- `Ry`, `Rm`, `E`, `ν`, `ρ`;
- свариваемость;
- нормативный источник;
- поддерживаемые диаметры;
- расчётная масса погонного метра `ρ·πd²/4`.

### Крепёж

Показываются:

- классы прочности болтов и `Rbun/Rbs/Rbt`;
- диаметры, шаг резьбы, `Ab/Abn`;
- справочная геометрия головки;
- обычные проходные гайки;
- длинные соединительные гайки;
- источник каждого набора данных.

### Сварочные материалы

Показываются:

- электрод или проволока;
- процесс;
- `Rwun`, `Rwf`;
- стандарт;
- доступные катеты.

## Принцип «короткий ответ → доказательство → детали»

Главный экран результата не должен начинаться с 20–30 равноправных метрик. Порядок следующий:

1. ответ на выбранный сценарий;
2. 4–6 ключевых показателей;
3. объяснение определяющего критерия;
4. краткая схема алгоритма;
5. верификация;
6. подробные результаты.

Так пользователь сначала понимает **ответ**, затем **почему**, и только затем погружается в матрицы, элементы и огибающие.
