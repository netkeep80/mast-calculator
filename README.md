# Mast Calculator

Простое статическое веб-приложение для параметрического расчёта модульной телекоммуникационной мачты. Оно не требует сервера, сборщика и внешних JavaScript-библиотек: расчёт выполняется непосредственно в браузере и может публиковаться через GitHub Pages.

## Прототип 0.1

Реализовано:

- генерация пространственной схемы из одинаковых модулей;
- линейный расчёт идеальной 3D-фермы методом конечных элементов;
- собственный вес стержней;
- ветровая нагрузка на цилиндрические стержни и оборудование;
- дополнительная горизонтальная и вертикальная нагрузка на вершине;
- проверка растянутых стержней по текучести;
- упругая проверка сжатых стержней по Эйлеру;
- контроль численной невязки и индикатор плохой обусловленности;
- интерактивная визуализация расчётной схемы;
- первичный подбор минимального стандартного диаметра по прочности и отклонению;
- автоматические аналитические тесты;
- автоматическая публикация в GitHub Pages.

## Важное ограничение

Текущая версия является проверяемым физическим прототипом, а не готовым нормативным заключением. Она пока не учитывает конечную жёсткость и эксцентриситет узлов, болты, резьбу, сварные швы, фундамент, геометрическую нелинейность, общую потерю устойчивости, обледенение и усталость.

Топология одного модуля принята как горизонтальный равносторонний треугольник и шесть диагоналей к следующему уровню, повёрнутому на 60°. Эту схему необходимо сверить с фактическими размерами и расположением гаек.

## Локальный запуск

Для интерфейса достаточно любого статического HTTP-сервера, например:

```bash
python3 -m http.server 8080 --directory site
```

После этого открыть `http://localhost:8080`.

Тесты расчётного ядра:

```bash
npm test
npm run check
```

Зависимостей npm у проекта нет; Node.js используется только для автоматических тестов.

## Единицы

Внутри расчётного ядра используются единицы СИ: метры, ньютоны, паскали и килограммы. Интерфейс преобразует миллиметры, гигапаскали и мегапаскали на границе системы.
