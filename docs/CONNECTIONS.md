# Межмодульный болт и сварные концы рёбер

Статус: расчётная модель прототипа **1.2**.

Практический выбор деталей и их геометрия подробно описаны в [`JOINT_CONFIGURATOR.md`](JOINT_CONFIGURATOR.md). Этот документ фиксирует расчёт усилий и несущей способности.

## 1. Граница модели

Глобальная пространственная рамная модель считает общие геометрические узлы идеально жёсткими. После FEM отдельный connection-layer проверяет физические метизы и сварные концы. Податливость соединения пока не возвращается в глобальную матрицу `K`.

Для каждого load case сохраняются совпадающие `N/V/T/M`; независимые максимумы разных направлений ветра не смешиваются.

## 2. Физическая сборка issue #21

На каждом внутреннем FEM-узле сходятся шесть рёбер:

```text
нижний модуль: 4 ребра
верхний модуль: 2 ребра ножки
```

Реальный стык состоит из:

```text
верхняя ножка:
  2 ребра -> обычная проходная гайка My
                  |
                  | болт Mx проходит свободно, y > x
                  v
нижний модуль:
  4 ребра -> длинная соединительная гайка Mx
                  ^
                  | болт Mx ввинчивается в резьбу
```

Таким образом:

- к проходной гайке ножки приварены 2 ребра;
- к длинной соединительной гайке верхнего узла приварены 4 ребра;
- болт не работает резьбой в проходной гайке;
- болт работает резьбой в длинной гайке;
- число внутренних физических стыков при `N>1`: `3·(N−1)`.

## 3. Откуда берётся demand болта

Из FEM берутся концевые усилия двух рёбер верхней ножки в одном и том же расчётном случае. Они переводятся в глобальные координаты и суммируются:

```text
Fjoint = F1 + F2
Mjoint = M1 + M2
```

Ось болта пока вертикальна:

```text
eb = [0,0,1]
Faxis = Fjoint·eb
Fperp = Fjoint - eb·Faxis
T = |Mjoint·eb|
Mb = |Mjoint - eb(Mjoint·eb)|
```

Знак осевой силы трактуется физически:

```text
Faxis > 0  -> контакт сжат, болт не растягивается этой частью силы
Faxis < 0  -> стык раскрывается, возникает прямое растяжение болта
```

Поэтому:

```text
Ndirect = max(0,-Faxis)
```

## 4. Эффективный радиус

В версии 1.2 пользователь больше не вводит `reff` произвольно. Он получается из выбранной длинной соединительной гайки:

```text
reff = s/2
```

где `s` — размер гайки под ключ.

Текущая консервативная surrogate-модель момента:

```text
Nt = max(0,-Faxis) + |Mb|/reff
Ns = |Fperp| + |T|/reff
```

Сжатие контакта не используется как уменьшение `Mb/reff`, потому что точное распределение контактных давлений и prying пока не моделируются.

## 5. Проверка болта

Для выбранных диаметра и класса используются расчётные сопротивления и площади из каталога проекта на основе СП 16.13330.2017.

```text
Nbs = Rbs·Ab·ns·γb·γc
Nbt = Rbt·Abn·γc
```

Совместное действие растяжения и среза:

```text
Ubolt = sqrt((Ns/Nbs)^2 + (Nt/Nbt)^2)
PASS: Ubolt <= 1
```

Отдельно может показываться характеристическая разрывная сила резьбового сечения:

```text
Nu = Rbun·Abn
```

`Nu` не называется допустимой эксплуатационной нагрузкой.

## 6. Геометрия двух гаек и длина болта

До прочностной проверки конфигуратор обязан пройти геометрические условия:

```text
проходная гайка имеет резьбу большего диаметра
D1(clearance nut) - dbolt >= 0.5 мм
зацепление помещается в длинную гайку
длина болта >= высота проходной гайки + длина зацепления + монтажный запас
```

По умолчанию:

```text
Lengagement = 2d
монтажный запас = 2 мм
```

Для M24 получаем M30 как минимальную проходную гайку, длинную M24×72 и стандартный болт длиной 80 мм.

Геометрический `FAIL` блокирует сборку даже при достаточной расчётной прочности болта.

## 7. Автоподбор и фиксация детали

В автоматическом режиме для каждого кандидата пересчитывается его собственный `reff`, после чего demand и `Ubolt` вычисляются заново. Подбор начинается с класса 8.8 и минимального стандартного диаметра.

После выбора физической сборки она фиксируется. Боковая несущая способность, статическая масса на вершине и поиск максимальной высоты проверяют **этот же** болт/гайки/длину; увеличение метиза внутри пробного предельного расчёта запрещено.

## 8. Сварные концы

Каждый конец каждого ребра использует совпадающие:

```text
N, Vy, Vz, T, My, Mz
```

Текущая круговая surrogate-модель сварной группы:

```text
Qaxial = |N| + 2|M|/rw
Qshear = |V| + |T|/rw
Qw = hypot(Qaxial,Qshear)
```

Проверяются две расчётные границы:

```text
lw,f = Qw/(βf·kf·Rwf·γc)
lw,z = Qw/(βz·kf·Rwz·γc)
```

И итог:

```text
lw = max(lw,f, lw,z, 4kf, 40 мм)
Lphysical = lw + 10 мм·nsegments
```

В `auto` выбираются базовый совместимый покрытый электрод, стандартный катет и три участка шва; затем они проходят ту же фактическую weld-check.

## 9. Что пока не входит в connection-layer

Даже после issue #21 не реализованы:

- расчёт срыва внутренней/наружной резьбы по фактическому материалу гайки;
- поля допуска резьбы, покрытия и реальная посадка болта в проходной гайке;
- смятие под гайкой/головкой/шайбой;
- prying;
- предварительная затяжка и slip-critical режим;
- точная контактная площадка между гайками;
- точные координаты сварных валиков;
- усталость;
- конечная вращательная/поступательная податливость узла.

Поэтому каталожные размеры должны быть подтверждены по фактически закупленным деталям, а финальная конструкция — проверена инженером и при необходимости испытанием.
