# Mast Calculator

Статическое веб-приложение для параметрического расчёта модульной телекоммуникационной мачты. Оно не требует сервера, сборщика и внешних JavaScript-библиотек: расчёт выполняется непосредственно в браузере и публикуется через GitHub Pages.

## Прототип 0.2

Реализовано:

- генерация пространственной схемы из одинаковых модулей;
- линейный расчёт идеальной 3D-фермы методом конечных элементов;
- собственный вес стержней и вес цилиндрического слоя льда;
- ветровая нагрузка на стержни с учётом пространственной проекции и увеличения диаметра при обледенении;
- ветровая и весовая нагрузка оборудования;
- огибающая по нескольким направлениям ветра;
- проверка растянутых стержней по текучести;
- упругая проверка сжатых стержней по Эйлеру с ограничением по текучести;
- линейный собственный расчёт общей потери устойчивости по геометрической матрице жёсткости;
- визуализация первой формы общей потери устойчивости;
- контроль невязки решения, локального равновесия каждого узла и глобального равновесия;
- подбор минимального стандартного диаметра по прочности, отклонению и общей устойчивости;
- автоматические аналитические тесты и публикация в GitHub Pages.

## Расчёт общей устойчивости

После линейного статического расчёта по найденным продольным усилиям собирается геометрическая матрица жёсткости `K_G`. Критический множитель нагрузки определяется из задачи

```text
(K + λ K_G) φ = 0.
```

Для численного решения используется преобразование через разложение Холецкого упругой матрицы `K`, после чего вычисляется максимальное собственное значение симметричной преобразованной матрицы. В интерфейсе можно показать соответствующую нормированную форму потери устойчивости.

## Важное ограничение

Текущая версия является проверяемым физическим прототипом, а не готовым нормативным заключением. Линейный собственный расчёт общей устойчивости не учитывает начальную кривизну, монтажные отклонения и геометрическую нелинейность. Пока также не учитываются конечная жёсткость и эксцентриситет узлов, болты, резьба, сварные швы, фундамент и усталость.

Топология одного модуля принята как горизонтальный равносторонний треугольник и шесть диагоналей к следующему уровню, повёрнутому на 60°. Эту схему необходимо сверить с фактическими размерами и расположением гаек.

## Локальный запуск

```bash
python3 -m http.server 8080 --directory site
```

После этого открыть `http://localhost:8080`.

Тесты расчётного ядра:

```bash
npm test
npm run check
```

Зависимостей npm у проекта нет; Node.js используется только для автоматических тестов.

## Единицы

Внутри расчётного ядра используются единицы СИ: метры, ньютоны, паскали и килограммы. Интерфейс преобразует миллиметры, гигапаскали и мегапаскали на границе системы.
