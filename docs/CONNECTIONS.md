# Межмодульный болт и сварные концы рёбер

Статус: расчётная модель прототипа 1.0.

## 1. Назначение

Глобальная FEM мачты по-прежнему считает каждый геометрический узел идеально жёстким. Этот документ описывает отдельный post-processing слой, который отвечает на два практических вопроса issue #15:

1. какое усилие получает один реальный межмодульный болт, выдерживает ли выбранный размер/класс и какой минимальный стандартный диаметр нужен при разных классах прочности;
2. какая минимальная суммарная длина угловых швов нужна на каждом конце каждого ребра и какой уровень сварочного материала нужен.

Расчёт соединений не создаёт новую независимую FEM. Он использует совпадающие конечные `N/V/T/M` уже рассчитанного frame load case.

## 2. Физическое разделение узла

На каждом внутреннем уровне геометрический FEM-узел содержит шесть рёбер.

По принятой технологии модульной сборки они разделяются так:

```text
нижний модуль:
  2 диагонали, приходящие снизу
  2 ребра горизонтального треугольника
  = 4 ребра

верхний модуль:
  2 диагонали следующей ножки
  = 2 ребра
```

Один вертикальный межмодульный болт соединяет двухреберную ножку верхнего модуля с четырехреберной частью нижнего модуля.

Поэтому для `N` модулей число внутренних болтов:

```text
Njoints = 3*(N - 1), N > 1
```

Три нижних фундаментных узла сюда не входят. Они должны проверяться как отдельный тип соединения с конкретной конструкцией фундамента.

## 3. Как из FEM получается нагрузка на болт

Для каждого внутреннего узла выбираются ровно два member, идущие на следующий уровень. Их конечные силы и моменты в общей системе координат суммируются:

```text
Fjoint = F1 + F2
Mjoint = M1 + M2
```

Это важно: компоненты одного demand всегда принадлежат **одному и тому же load case**. Нельзя составлять искусственный вектор из максимального `N` одного направления ветра, максимального `V` другого и максимального `M` третьего.

Ось болта в текущей физической модели вертикальна:

```text
eb = [0, 0, 1]
```

Прямые составляющие:

```text
Faxis = Fjoint · eb
Fperp = Fjoint - eb*Faxis

Nt,direct = |Faxis|
Ns,direct = |Fperp|
```

Жёсткая frame-модель может передавать через узел момент. Один идеальный центральный болт сам по себе не задаёт плечо, поэтому вводится явный физический параметр:

```text
reff = jointEffectiveRadiusMm
```

Он должен соответствовать реальной контактной геометрии гайки, шайбы, торца, упора или другого элемента, через который момент замыкается в соединении.

Консервативное приведение:

```text
Nt = Nt,direct + |Mb|/reff
Ns = Ns,direct + |T|/reff
```

где `Mb` — модуль момента, перпендикулярного оси болта, `T` — момент вокруг оси болта.

Это не скрытая константа: `reff` показан в UI, сохраняется в snapshot и печатается в расчётном проекте.

Для контроля порядка величины используется стандартная формула площади растягиваемого сечения метрической резьбы:


Но расчётная несущая способность использует именно табличное `Abn` СП 16.

## 5. Несущая способность болта

Для одного болта и `ns` расчётных плоскостей среза:

```text
Nbs = Rbs * Ab * ns * gamma_b * gamma_c
Nbt = Rbt * Abn * gamma_c
```

В текущей модели один межмодульный болт является одноболтовым соединением, поэтому для среза принято:

```text
gamma_b = 1.0
```

`gamma_c` остаётся явным параметром `connectionConditionFactor`.

Совместное действие среза и растяжения проверяется согласно 14.2.13 СП 16:

```text
Ubolt = sqrt((Ns/Nbs)^2 + (Nt/Nbt)^2)
PASS: Ubolt <= 1
```

Дополнительно для понятной пользователю «разрывной нагрузки» выводится:

```text
Nu,characteristic = Rbun * Abn
```

Это **не допускаемая рабочая нагрузка** и не подменяет `Nbt`. Это характеристическая нормативная оценка разрушения резьбового сечения до применения расчётной модели сопротивлений.

## 6. Подбор диаметра при разных классах прочности

Для каждого класса `5.6 / 5.8 / 8.8 / 10.9 / 12.9` все физические joint demand всех эксплуатационных load cases проверяются по возрастанию диаметра:

```text
M16 -> M20 -> M24 -> M30 -> M36 -> M42 -> M48
```

Первый размер, для которого все совпадающие `Nt/Ns` проходят взаимодействие, становится минимальным рекомендованным размером этого класса.

Результат хранит:

```text
boltClass
recommended diameter/pitch
governing level/node/load case
Nt, Ns
Nbt, Nbs
Ubolt
Nu,characteristic
```

## 7. Болт включён в специальные пределы мачты

### 7.1. Боковая сила вершины

Для единичного бокового случая дополнительно вычисляется:

```text
Fbolt = 1/Ubolt(F0=1 N)
```

Первый предел теперь:

```text
Flim = min(Fmember, Fglobal, Fbolt)
```

То есть слабый межмодульный болт может честно стать механизмом первого бокового предела.

### 7.2. Статическая масса вершины

В каждой итерации двоичного поиска массы проверяются одновременно:

```text
Umember(m) <= 1
Ubolt(m) <= 1
lambda_cr(m) >= 1
```

Поэтому статический предел также может определяться соединительным болтом.

## 8. Сварка каждого конца ребра

Для каждого member и каждого его конца берётся **один совпадающий набор** локальных конечных усилий:

```text
N
Vy, Vz
T
My, Mz
```

Для каждого ветрового load case сварная проверка выполняется отдельно; затем для физического конца выбирается случай с максимальной требуемой длиной.

Это сохраняет физическую корреляцию усилий.

## 9. Сварочные сопротивления

Каталог использует таблицу Г.2 СП 16:

| Материал/уровень | Rwun, МПа | Rwf, МПа |
|---|---:|---:|
| Э42А | 410 | 180 |
| Э46А | 450 | 200 |
| Э50А / УОНИ-13/55 | 490 | 215 |
| Св-08Г2С, базовый уровень Э50 | 490 | 215 |
| Э60 | 590 | 240 |
| Э70 | 685 | 280 |
| Э85 | 835 | 340 |

По границе сплавления:

```text
Rwz = 0.45 * Run
```

где `Run` — временное сопротивление более слабого из соединяемых основных металлов.

Для выбора сварочного материала приложение дополнительно требует:

```text
Rwun >= Run
```

и показывает минимальный уровень отдельно для электрода и для проволоки.

## 10. Идеализация сварной группы

Фактическая пространственная геометрия трёх сварных участков вокруг арматуры и гайки пока задаётся только количеством участков, катетом и эффективным радиусом. Поэтому для передачи `N/V/T/M` применяется консервативная круговая surrogate-модель.

Для радиуса сварной группы `rw`:

```text
Qaxial = |N| + 2*|M|/rw
Qshear = |V| + |T|/rw
Qw = sqrt(Qaxial^2 + Qshear^2)
```

Далее два обязательных сечения углового шва:

```text
lw,f = Qw/(beta_f*kf*Rwf*gamma_c)
lw,z = Qw/(beta_z*kf*Rwz*gamma_c)
```

Расчётная эффективная суммарная длина:

```text
lw = max(lw,f, lw,z, 4*kf, 40 mm)
```

СП 16 определяет расчётную длину как суммарную длину непрерывных участков за вычетом 10 мм на каждом таком участке. Поэтому для `nsegments`:

```text
Lphysical,total = lw + 10 mm*nsegments
Lphysical,segment = Lphysical,total/nsegments
```

Последнее деление — только технологическая подсказка при равном распределении длины; реальные участки могут иметь неодинаковую длину, если их групповая геометрия проверена отдельно.

## 11. Почему длина сварки пока является консервативной оценкой

СП 16 для момента использует геометрические характеристики фактического расчётного сечения сварной группы (`W`, `Ix`, `Iy`). Пока координаты реальных сварных валиков вокруг конкретной гайки не введены, программа не имеет права притворяться, что знает эти величины.

Поэтому текущая версия делает две вещи явно:

1. не выбрасывает моменты `My/Mz/T` из frame-result;
2. приводит их к силе через явный `rw`, создавая консервативную оценку необходимой суммарной длины.

После задания точных координат и длины каждого валика этот слой можно заменить прямой реализацией 14.1.17–14.1.19 без изменения глобального FEM.

## 12. Что версия 1.0 не смешивает с этой проверкой

Следующие механизмы требуют дополнительных реальных размеров узла и поэтому не выдаются как будто уже рассчитанные:

- смятие детали под болтом;
- вырыв/срез внутренней резьбы гайки или удлинённой муфты;
- изгиб/раскрытие шайбы и prying;
- затяжка, трение и проскальзывание;
- усталость резьбы и сварки;
- локальная пластичность металла гайки;
- конечная вращательная/поступательная жёсткость стыка;
- реальное распределение напряжений между отдельными сварными валиками;
- фундаментный болт и опорная плита.

Это не «отложенная часть issue #15», а граница исходных данных: без размеров конкретной гайки/шайбы/резьбового зацепления такие числа были бы выдуманными. Версия 1.0 полностью решает именно поставленные в issue задачи расчётной/разрывной проверки **самого болта** и минимальной **суммарной длины угловых швов** с подбором сварочного материала.

## 13. Верификация

Обязательные regression-проверки:

```text
M24 8.8:
  Nbs = 332*452
  Nbt = 451*353
  Nu = 830*353

combined:
  sqrt(0.8^2 + 0.6^2) = 1

100 kN pure tension, class 8.8:
  M16 fails
  M20 passes

weld pure axial:
  lw,f = N/(beta_f*kf*Rwf*gamma_c)
```

Дополнительно проверяются:

- M24×3: формульная площадь `As` близка к табличным 353 мм²;
- ровно три межмодульных болта для двух модулей;
- два верхних member в каждом таком стыке;
- отсутствие выдуманного внутреннего болта у одномодульной модели;
- монотонный рост болтового предела при увеличении размера/класса;
- один определяющий load case на каждый физический конец сварки;
- минимум `40 мм` и `4kf`;
- рекомендации Э50А/УОНИ-13/55 и Св-08Г2С для принятого `Run=490 МПа`;
- UI/report/snapshot/CI contracts.
