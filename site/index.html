Исходные данные

Изготовление модуля

Модуль считается правильным октаэдром: все девять его рёбер имеют одну длину a, а высота между треугольными гранями вычисляется как h = a·√(2/3). Ширина реза, торцевая подрезка и нахлёст реальной арматуры на соединительный элемент пока не меняют осевую FEM-геометрию.

Межмодульный болт и сварка

Внутренний узел трактуется буквально по геометрии мачты: четыре ребра нижнего модуля остаются на нижней стороне стыка, а два ребра следующей «ножки» передают совпадающие F/M через один вертикальный болт. Изгибающий момент переводится в дополнительное растяжение через заданный эффективный радиус, кручение — в дополнительный срез. Для реального M24×3 радиус должен быть уточнён по фактической шайбе/гайке/контактной площадке.

Нагрузки и погода

Сценарии Бофорта используют характерные скорости ветра и переводят их в динамическое давление q = ρv²/2 при ρ = 1,225 кг/м³. Это сравнительная шкала, а не замена нормативному ветровому району, порывам и коэффициентам высоты.

Расчётные коэффициенты и ограничения

Для локальной проверки ребра по Эйлеру μ = 0,5. Для одного межмодульного болта по умолчанию используется одна плоскость среза и γb = 1,0; поле γc оставлено явным. βf/βz должны соответствовать реальному способу сварки и таблице 39 СП 16.
