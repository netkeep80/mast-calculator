# Калькулятор мачты

Статическое браузерное приложение для расчёта модульной мачты из сварных арматурных октаэдров. Backend не требуется: тяжёлые вычисления выполняются в Web Worker, публикация — через GitHub Pages.

Опубликованная версия: **https://netkeep80.github.io/mast-calculator/**

## Прототип 1.3 — сначала практический вопрос, затем FEM

Интерфейс больше не начинается с большого набора равноправных инженерных полей. Пользователь сначала выбирает один из четырёх основных сценариев:

1. **Проверить конкретную мачту** — выдержит ли выбранная конструкция заданную погоду и оборудование;
2. **Подобрать конструкцию** — минимальный проходящий диаметр арматуры и согласованный соединительный узел;
3. **Узнать пределы** — максимальная высота, боковая сила, статическая масса на вершине и эквивалентный объём воды;
4. **Проверить расчёт** — алгоритм, residuals, global/Schur/dense cross-check, паспорт верификации и справочники исходных величин.

Общий UX-поток:

```text
задача
  ↓
конструкция
  ↓
условия эксплуатации
  ↓
соединение (auto по умолчанию)
  ↓
расчёт
  ↓
короткий ответ
  ↓
почему получен этот ответ?
  ↓
подробные таблицы / 3D / верификация / справочники
```

Подробный UX-контракт: [`docs/USAGE_SCENARIOS.md`](docs/USAGE_SCENARIOS.md).

## Что пользователь вводит, а что вычисляется

В основной форме вводятся реальные производственные и эксплуатационные параметры: число модулей, закупочная длина и раскрой прутка, диаметр и класс арматуры, погодный сценарий, оборудование и обледенение.

Автоматически, но видимо для проверки, вычисляются:

```text
a = Lstock / nparts
h = a·sqrt(2/3)
масса одного ребра
Ry, Rm, E, ν, ρ материала
ветровое давление погодного сценария
геометрия auto-конфигуратора узла
```

Ручные параметры соединения и инженерные коэффициенты сохранены, но находятся в раскрываемых разделах. Это progressive disclosure: они доступны специалисту, но не мешают базовому сценарию.

## Масса физической сборки

После расчёта отдельно показываются понятные производственные величины:

- масса одного ребра;
- масса одного полного межмодульного узла со сваркой: две гайки, болт и шесть сваренных концов рёбер;
- масса одного сваренного и закреплённого модуля: девять рёбер, три длинные гайки, три проходные гайки, три болта и 18 сваренных концов;
- оценка массы всей изготовленной мачты из одинаковых модулей.

Масса арматуры считается по `m = ρ·πd²/4·L`. Масса метизов — прозрачная геометрическая оценка по справочным размерам, а не паспортная масса изделия конкретного производителя. Масса углового шва оценивается через идеализированную площадь наплавленного металла `Aweld ≈ k²/2`.

Для унифицированного физического модуля на все 18 концов применяется критическая требуемая физическая длина шва из расчётной огибающей. Это консервативнее, чем изготавливать каждый конец с индивидуальной длиной.

**Важно:** эта сборочная масса пока не добавляется автоматически к собственному весу global FEM. Длина шва определяется после FEM по усилиям; немедленное включение её массы породило бы скрытую обратную связь `усилия → длина шва → масса → усилия`. В интерфейсе, документации и данных это ограничение указано явно. FEM-собственный вес сейчас остаётся массой арматурных рёбер.

## Справочники исходных расчётных данных

Внизу приложения есть раскрываемый раздел справочников. Он строится **из тех же JavaScript-каталогов, которые использует расчёт**, поэтому UI не содержит второй копии чисел.

Показываются:

- классы арматуры: `Ry`, `Rm`, `E`, `ν`, `ρ`, свариваемость, источник;
- поддерживаемые диаметры арматуры, площадь и расчётная масса 1 м;
- классы прочности болтов и `Rbun/Rbs/Rbt`;
- болты: шаг, `Ab/Abn`, справочная геометрия головки;
- обычные проходные и длинные соединительные гайки;
- электроды и сварочная проволока: `Rwun/Rwf`, процесс и нормативный источник;
- поддерживаемые катеты углового шва.

Справочники предназначены именно для аудита входных чисел программы. Они не заменяют паспорт конкретной покупной партии арматуры, болта, гайки или электрода.

## Физический модуль

Каждый правильный октаэдр установлен **ножками вниз**:

```text
3 ребра верхнего треугольника
6 диагональных ножек
-----------------------------
9 рёбер на модуль
```

Геометрия:

```text
a = Lstock / nparts
R = a / sqrt(3)
h = a*sqrt(2/3)
H = N*h
```

Три нижних узла production-модели пока являются идеальной жёсткой заделкой по всем шести степеням свободы. Отдельные аналитические statics-tests из issue #26 используют точечные опоры без опорных моментов исключительно как verification fixture.

## Расчётное ядро

Каждый узел имеет 6 DOF `ux, uy, uz, rx, ry, rz`. Каждое ребро — пространственный Euler–Bernoulli frame element. Узлы global FEM идеализированы абсолютно жёсткими. После решения восстанавливаются `N, Vy, Vz, T, My, Mz` и отдельно проверяются арматура, межмодульный болт и сварные концы.

Статическая задача проверяется тремя вычислительными путями:

1. **global FEM** — symmetric-band Cholesky;
2. **module-by-module** — точная Schur-конденсация 18-DOF интерфейсов;
3. **independent dense reference FEM** — отдельная сборка элементов и Gaussian elimination.

CI сравнивает перемещения/повороты, реакции и локальные концевые усилия. Для выбранных задач независимо сравнивается и `λcr`.

## Соединительный узел

Межмодульный стык:

```text
2 ребра ножки → обычная проходная гайка My
                    │
                    │ болт Mx проходит свободно
                    ▼
4 ребра узла  → длинная соединительная гайка Mx
                    ▲
                    │ болт Mx ввинчивается сюда
```

Auto-конфигуратор выбирает болт, класс прочности, обе гайки, длину болта, длину зацепления и базовые параметры сварки. После эксплуатационного расчёта выбранная физическая сборка фиксируется и не может увеличиваться внутри поиска боковой нагрузки, статической массы или максимальной высоты.

Подробнее: [`docs/JOINT_CONFIGURATOR.md`](docs/JOINT_CONFIGURATOR.md) и [`docs/CONNECTIONS.md`](docs/CONNECTIONS.md).

## Верификация

Паспорт верификации строится как цепочка независимых свидетельств: простые формулы геометрии и массы, равновесие сил и моментов, residual `K·u-F`, аналитические beam/frame задачи, global ↔ Schur, independent dense reference FEM, отдельные статически определимые тесты реакций трёх опор и eigen-buckling residual.

Внешний КЭ-комплекс, инженерная рецензия и натурные испытания остаются **НЕ ПРОВЕРЕНО**, пока реально не выполнены.

Подробнее: [`docs/VERIFICATION_FOR_NON_SPECIALISTS.md`](docs/VERIFICATION_FOR_NON_SPECIALISTS.md), [`docs/TRIPLE_SOLVER_VERIFICATION.md`](docs/TRIPLE_SOLVER_VERIFICATION.md), [`docs/SUPPORT_REACTION_STATICS.md`](docs/SUPPORT_REACTION_STATICS.md).

## Что пока не доказано

Совпадение внутренних решателей и большое число тестов не превращают прототип в нормативный сертификат. Открыты как минимум P-Delta/геометрическая нелинейность, initial imperfections, пластичность, конечная податливость узла, thread stripping по материалу конкретной гайки, реальные допуски/покрытия резьбы, bearing/prying/preload/slip, точная геометрия сварных валиков, усталость, параметрический фундамент, полный набор нормативных сочетаний, согласованное включение массы метизов/сварки в self-weight и независимая проверка реальной мачты сторонним FEM/натурными испытаниями.
